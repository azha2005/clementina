## Input Routine de Ferranti

La edición incluye `input_routine/`, la transcripción y reconstrucción que
usan las pruebas, el CLI y el pupitre WebAssembly. La fuente histórica es el
*Annotated Input Routine*, CS 240, de julio de 1959 con agregados de 1960.
Las fuentes que reproducen código histórico y las imágenes ensambladas a
partir de ellas conservan los términos que correspondan al material original.
La licencia MIT cubre el código propio, incluido el enlazador, el ensamblador
y el emulador.

El [PDF oficial](https://www.homepages.ed.ac.uk/jwp/history/mercury/manual/inputroutine/mercury-ip.pdf)
lleva un aviso de © Edinburgh University Library. La biblioteca lo facilita
para investigación y estudio privado y pide permiso previo para reproducirlo
o hacer copias. Esta edición enlaza al ejemplar de la biblioteca. La atribución
y este aviso no constituyen un permiso de reproducción ni acreditan autorización
para redistribuir el escaneo o el contenido histórico transcripto.
